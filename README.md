# Sentient Extension

**Sentient is Everywhere** is a powerful browser extension that brings the capabilities of Sentient AI to any page on the web. With this extension, you can select text on any website and ask Sentient AI to **summarize**, **explain**, **translate**, or **send it to a new chat** — all with a simple right-click.

---

##  Features

- **Text Summarization** – Quickly summarize long articles, blog posts, or any selected text  
- **Explanation Requests** – Get clear explanations of complex topics or technical terms  
- **Translation** – Translate selected text to your preferred language  
- **New Chat** – Instantly send selected text to a new Sentient chat  
- **Quick Slash Commands** – Use `/st` while browsing to instantly launch Sentient  
- **Custom Commands** – Define your own prompts to personalize the experience  
- **Universal Compatibility** – Works seamlessly on Google, Discord, Twitter, YouTube, and more  

---

##  Smart Slash Integration

While browsing platforms like Discord, YouTube, or Google, users can simply type `/st` to instantly send their input to Sentient — no need to manually open a chat page.

This allows for real-time use of Sentient AI while researching, chatting, or reading — dramatically improving productivity.

---

## ⚙️ Customization & Power Features

One of the strongest features of the extension is its **deep customization**:

- From the settings menu, users can define **custom commands** tailored to their needs.  
- By using the `<selectedtext>` placeholder, they can automatically insert any word, tag, or prompt around the selected content.
