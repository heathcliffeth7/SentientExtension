# sentient-extension
Sentient is Everywhere is a useful extension that brings the power of Sentient AI to any page on the web. With this extension, you can select text on any website and use Sentient AI's capabilities to summarize, explain, translate, or send this text to a new chat.
Features:
Text Summarization: Quickly summarize long articles, blog posts, or any text
Explanation Requests: Get clear explanations of complex topics or technical terms
Translation: Translate selected text to your desired language
New Chat: Send selected text to a new Sentient chat
Custom Commands: Add your own custom commands to personalize the extension
Universal Compatibility: Works on Google, Discord, Twitter, and other popular platforms
How to Use:
Select text on any web page
Right-click on the selected text
Choose the desired Sentient operation from the menu (Summarize, Explain, Translate, etc.)
See the results instantly or continue in a new Sentient chat
Customization:
From the extension settings, you can choose which features appear in the right-click menu and add your own custom commands.
With Sentient is Everywhere, carry your AI assistant with you everywhere and make your web experience more efficient!
